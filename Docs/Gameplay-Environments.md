# Authored gameplay context scenes

The six scenes are editable Blender meshes exported by `tools/art/Create-GameplayEnvironments.py`. Source files are in `ArtSource/GameplayEnvironments`, exports and eight 512px albedo/normal maps in `Assets/_Project/Art/GameplayEnvironments`. `ArtSource/GameplayEnvironments/mesh-audit.json` records mesh, UV, vertex and triangle counts. The composition is a reconstruction guided by the gameplay reference; it is not a verified pixel match.

`EnvironmentAssetPipeline.Install` remaps every imported material to persistent assets and creates `Resources/Environments/GameplayEnvironmentSet.prefab`. Run the timber and crew importers first. Missing meshes, maps, materials or character prefabs fail explicitly. The environment controller never constructs substitute primitive scenery.

The prefab has mutually exclusive Explore, Mine, Factory, Workshop, Boutique and RegionMap roots, at X coordinates 0, 40, 60, 80, 100 and 120. Explore retains the hero timber entrance, imported ore carts, profiled rails, contoured terrain, layered cliffs, vegetation and a small stream bridge. Mine contains an excavated rock room, timber supports, warm lanterns and dimensional crystal veins. The factory contains five distinct processing stations joined by conveyor meshes. The workshop and boutique have open-front rooms with benches, display furniture, bullion, gems and lights. The map has dimensional islands, vegetation, mountains and small mine portals.

`GameplayEnvironmentSet` exposes Create, TimberArea, BunkerLabels, ExploreRoot, InYard, SetMode, SetShown, Present and Frame. SetMode accepts the existing `mine`, `factory`, `craft`, `shop` and `map` screen names; other screen names show Explore. SetShown hides every root when the original Works view is active. Frame returns false for Explore so the existing follow camera retains movement behaviour. In Mine, Present displays the player's selected imported character and the live mining/carry pose. Factory/workshop role animation follows live busy jobs; it does not grant or spend items.

This import does not modify ownership, deposits, player coordinates, currency, jobs, upgrades or save codecs. The simulation still controls every interaction. Dedicated context geometry is a presentation view of that state. Runtime integration, camera framing, material appearance, live interactions and device performance require the recorded Unity validation results; mesh export alone does not establish those results.

Known remaining art checks: the reconstruction does not establish the requested 95% character score or <=0.5% UI bounds target. Additional distant plots remain data; only the starter area is modelled here. Transparent glass/water use the project lens shader, whose mobile overdraw and transparency ordering need device profiling. No physical-device performance result is supplied by this asset pipeline.
