## Build and rollout gates

[Google currently requires API 36 for new mobile apps/updates](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en-mt). Target settings use API 36 and ARM64; verify 16 KB native-library packaging and actual device compatibility in the produced AAB. A test APK can include x86_64. An AAB requires the owner's external upload key. No signed AAB or Play pre-launch report exists.

[Apple requires iOS/iPadOS 26 SDK or later for uploads from 28 April 2026](https://developer.apple.com/news/?id=ueeok6yw). Export the Unity Xcode project, then use compatible macOS/Xcode, the owner's team, valid bundle IDs and provisioning for device/archive validation and TestFlight. Minimum app OS is iOS 15; that differs from the build SDK. An export is not a signed iOS app.

Start with internal Android testing and TestFlight after technical QA. Satisfy the actual account's closed-test requirements, review privacy declarations/permissions, collect device feedback and resolve release blockers. Prepare a limited staged rollout and rollback/update-save recovery plan. Owner review and explicit publication authorization are the final gate; no submission/upload has been performed.
