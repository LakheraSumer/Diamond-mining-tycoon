# Asset provenance and dependencies

| Item | Provenance / terms | Current use |
| --- | --- | --- |
| Simulation, economy, UI and project tools | Original project-authored source | Implemented |
| Mine meshes, faceted gems, workers, palettes and synthesized tones | Generated by original source in MinePresenter/GameAudio | Implemented; presentation QA not run |
| AppIcon and store illustration | Original geometric generator, tools/Generate-StoreArt.py; no reference imagery | App icon source wired to editor settings; store drafts inspected |
| Promotional text rendering | Existing system font rasterized by Pillow; no font file redistributed | Draft graphic only |
| Unity 6000.3.26f1 | Unity terms and appropriate owner license | Desktop Hub Personal license active; project imported and entered Play on 20 October |
| Bundled uGUI 2.0.0 and built-in modules | Unity-distributed packages; exact manifest versions retained | API compilation passed; desktop Unity import resolved actual packages and generated packages-lock.json |
| LegacyRuntime font | Unity-distributed runtime font | Used by game UI |
| Android SDK / NDK r27c / OpenJDK17 / CMake | Official Google/Unity archives; original license notices retained in tool directories | Project-local build prerequisites; not proprietary reference assets |
| Xcode / Apple SDK | Apple terms | No supplied Mac environment; archive not built |
| Test SDK 17.11.1 / NUnit 4.2.2 / NUnit3TestAdapter 4.6.0 | Package licenses retained in NuGet cache | Test-only; not shipped in player |
| Pillow | Existing Python imaging library, used for deterministic original art rendering | Tool-only; not a player dependency |
| REA 6.7.0 | Supplied MIT-licensed checkout with its own third-party notices | Local static analysis tooling only; never part of Assets/player |
| AdMob, analytics, crash-reporting or payment SDK | Not included | No production use |
| Paid art/audio/obfuscator packs | None purchased | No use |

Reference APKs and analysis output remain under analysis, outside production Assets. No extracted proprietary code, graphics, models, dialogue, layouts, music or credentials were copied into the game. Keep package/tool notices and re-audit provenance when adding any third-party asset or SDK. Final artwork/name and license eligibility need owner review; no claim is made that a Unity license was activated by installing the editor.
