# Costs

Verified against official public pages on 20 October 2026; USD unless stated otherwise. No purchase, paid deployment or developer enrollment was performed. Regional tax and exchange-rate totals are not estimated here.

| Item | One-time | Recurring / limits |
| --- | --- | --- |
| Unity Personal | No tool purchase if eligible | Free under the published eligibility threshold; Unity 6 splash is optional. Verify the owner's finances and terms. |
| Unity Pro if required | None assumed | Published 2026 price: $2,310/seat/year prepaid, or $210/seat/month. |
| Google Play account | $25 registration | Account verification/testing obligations also apply; no account access supplied. |
| Apple Developer Program | None assumed | $99/year, local pricing may differ. |
| Original procedural art/audio and tools used here | No asset purchases | No paid art, obfuscator, analytics or ad SDK added. |
| Mac/Xcode access | Owner hardware if already available | Rental/build-service cost unknown; no provider selected or account-specific quote obtained. Xcode itself is available without a tool purchase. |
| Backend / hosting / monitoring | None for the offline game | No deployed server or monitoring service; therefore no current hosting bill. A public privacy-policy/support site still needs owner provision. |
| Integrity / ad verification | Not integrated | No unlimited free-service claim. Future service quotas, account eligibility, provider terms and hosting must be rechecked before implementation. |

[Unity's 2026 pricing](https://unity.com/products/pricing-updates) gives the Personal threshold and Pro prices above. [Google registration guidance](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en) describes the one-time registration fee. [Apple membership](https://developer.apple.com/programs/) lists the annual fee.

[Google's new personal-account testing requirement](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en-GB) requires qualifying accounts created after 13 November 2023 to complete a closed test with at least 12 continuously opted-in testers for 14 days before applying for production access. Actual account eligibility/dashboard status remains unknown; no completed testing or guaranteed production approval is claimed.

Future Play Integrity configurations have quotas (the documented default includes 10,000 requests/day, with eligibility requirements for increases); see [official setup](https://developer.android.com/google/play/integrity/setup). No request budget, paid tier, App Attest deployment, ad payout or hosting price is assumed for this offline release.
